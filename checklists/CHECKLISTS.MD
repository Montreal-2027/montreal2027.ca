# Available Checklists

These checklists are intended to ensure that critical steps are not missed or forgotten. Use these the way that pilots use theirs. More checklists will be added in the future, so check the list often. Checklists are subject to updates, so make sure you have the most up-to-date version of a checklist.

| Checklist | Purpose |
|---|---|
| [Pre-commit](PRE-COMMIT.md) | Steps to take before committing changes |
| [Pull Requests](PULL_REQUESTS.md) | Steps to take before creating a Pull Request |
| [Releases](RELEASES.md) | Steps for a scheduled, hotfix, and content hotfix release|
